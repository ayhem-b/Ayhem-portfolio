Exercices

  1. Démarrez le convoyeur puis relâchez Marche : l'auto‑maintien (Q0.0 en parallèle) le garde en marche.
  2. Arrêtez‑le avec le bouton Arrêt (contact NO sur une entrée câblée NC).
  3. Pendant la marche, activez le capteur : le défaut M0.0 se verrouille, le buzzer clignote.
  4. Libérez le capteur, puis acquittez le défaut avec Arrêt.
  5. Forcez Q0.0 à ON, appuyez sur l'arrêt d'urgence et mesurez TP7 : pourquoi 0 V ?
